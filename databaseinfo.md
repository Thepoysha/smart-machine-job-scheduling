# Database Management Module

This module is developed as part of the Smart Machine and Job
Scheduling System.

## Developed By

Pragati Gupta

## Responsibilities

- MySQL database design
- Job data management
- Machine data management
- Schedule history management
- Database queries
- MySQL connectivity

## Database Tables

### Jobs
Stores job name, processing time, priority, status,
machine assignment and scheduling information.

### Machines
Stores machine details and availability.

### Schedules
Stores job scheduling history including algorithm,
machine, start time, finish time and waiting time.

## Technologies

- C
- MySQL
- MySQL Client Library

## Main Operations

- Connect to MySQL
- Add jobs
- Add machines
- View jobs
- View machines
- View schedule history
